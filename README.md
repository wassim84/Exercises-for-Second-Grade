# تطبيق الثانية ابتدائي (أندرويد)

تطبيق تمارين تفاعلية لتلاميذ السنة الثانية ابتدائي: رياضيات، قراءة، إنتاج كتابي، إيقاظ علمي، تربية إسلامية.
يكتب التلميذ إجاباته ثم يضغط «تحقّق»: الإجابة الصحيحة تظهر بالأخضر، والخاطئة بالأحمر مع عرض الإجابة الصحيحة.

## الهيكلة
- **Kotlin + Jetpack Compose**، واجهة عربية من اليمين إلى اليسار، يعمل بدون إنترنت.
- كل تمرين ملف JSON في `app/src/main/assets/exercises/<المادة>/`:
  `math` رياضيات، `reading` قراءة، `writing` إنتاج كتابي، `science` إيقاظ علمي، `islamic` تربية إسلامية.
- إضافة تمرين = إضافة ملف JSON فقط، دون تغيير في الكود.
- التصحيح يتسامح مع الشكل (الحركات)، الهمزات، الأرقام العربية/الهندية (١٢ = 12)، والفراغات الزائدة.

## صيغة التمرين
```json
{
  "id": "math-01",
  "title": "الجمع إلى 20",
  "instructions": "أحسب ثم اكتب النتيجة:",
  "text": "نص قراءة اختياري يظهر فوق الأسئلة",
  "questions": [
    {"type": "input",     "prompt": "7 + 5 = ……", "answers": ["12"]},
    {"type": "choice",    "prompt": "أيّ عدد أكبر؟", "options": ["14", "41"], "answers": ["41"]},
    {"type": "truefalse", "prompt": "8 + 8 = 16", "answers": ["صحيح"]},
    {"type": "open",      "prompt": "أكتب جملتين عن لعبتي.", "answers": ["نموذج إجابة يُعرض بعد الإنهاء"]}
  ]
}
```
- `input`: خانة كتابة، `answers` = كل الإجابات المقبولة.
- `choice`: اختيار من متعدد، الإجابة نص أحد الخيارات.
- `truefalse`: صحيح / خطأ.
- `open`: كتابة حرة (لا تُصحَّح آليًا)، يُعرض نموذج إجابة بالأزرق.

## تحويل الوثائق
ترفع ورقة التمارين (صورة / PDF / Word) في المشروع، فيحوّلها Claude إلى ملف JSON بهذه الصيغة ويضيفها للمجلد المناسب.

## البناء
- عبر GitHub: عند كل push يبني `.github/workflows/build.yml` ملف APK ويضعه في Artifacts.
- محليًا: افتح المجلد في Android Studio، أو `./gradlew assembleDebug`.
- الاختبارات `./gradlew testDebugUnitTest` تتحقق من منطق التصحيح ومن صلاحية كل ملفات التمارين.
